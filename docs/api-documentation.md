# API documentation

Base URL: `http://127.0.0.1:8000/api`; interactive schema: `/docs`. Complaint creation accepts name, email, location, area, complaint_text, date (`YYYY-MM-DD`) and time. Analysis returns processed text, source/confidence, sentiment/score, estimated severity/score, urgency and keywords. Listing filters accept area, source, severity, sentiment_filter and search. CSV export accepts the same filters.
